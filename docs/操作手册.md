# MailPost 操作手册

本系统只用 **Gmail SMTP** 发信。打开 [http://localhost:3000](http://localhost:3000)。

侧栏入口：

| 菜单 | 做什么 |
| --- | --- |
| 写信 | 选 Gmail、填收件人、发一封 |
| 群发 | 勾选多人，同一封内容按日限额排队发 |
| Gmail | 接入 / 更新发件邮箱 |
| 联系人 | 自己添加收件人 |
| 话术 | 保存、修改可复用的标题和正文 |
| 已发送 | 查看发出记录和排队中的信 |
| 设置 | 签名名称、地址、退订用的站点地址 |

启动：

```bash
cd d:\mailpost
npm run dev
```

数据存在 `data/mailpost.json`，发出的真实邮件走 Gmail，不走沙箱。

---

## 一、添加发件邮箱（Gmail）

系统只接受 `@gmail.com`。密码必须是 **应用专用密码**，不是网页登录密码。

### 1. 在 Google 账号里准备 SMTP

1. 用要发信的 Gmail 登录。
2. 打开 [两步验证](https://myaccount.google.com/security)，确保已开启。
3. 打开 [应用专用密码](https://myaccount.google.com/apppasswords)。
4. 应用选「邮件」，设备选「Windows 计算机」，生成。
5. 得到 16 位密码（中间可能有空格，填进系统时有没有空格都可以）。

没有两步验证，就看不到应用专用密码页面。

### 2. 在 MailPost 里接入

1. 打开 **Gmail** 页：http://localhost:3000/mailboxes
2. 右侧填：
   - **Gmail 地址**：`you@gmail.com`
   - **显示名**：收件人看到的发件人名字，例如 `lily`
   - **应用专用密码**：上一步那 16 位
3. 点 **接入**

系统会自动写死：

- SMTP 主机 `smtp.gmail.com`
- 端口 `587`
- STARTTLS
- 强制 IPv4（本机开代理时避免连接被掐）

接入成功后，左侧出现这只邮箱，状态一般是 **养号 D1**。

### 3. 以后改密码

同一页卡片里「更新应用专用密码」，填新的 16 位，点 **更新**。Google 撤销旧应用密码后必须走这一步，否则发信会失败。

### 4. 接入失败常见原因

| 现象 | 原因 |
| --- | --- |
| 提示只支持 Gmail | 地址不是 `@gmail.com` |
| 提示已经接入 | 同一地址加过了 |
| 发送时报 `Invalid login` | 填了登录密码，或应用专用密码失效 |
| 发送时报 `Connection closed unexpectedly` | 代理 / IPv6；系统已按 IPv4 处理，仍失败就检查代理是否放行 `smtp.gmail.com:587` |

## 二、养号

接入那一刻开始计「养号第 1 天」。  
本系统的养号 **不是** 自动互发、自动回信。它只做一件事：**按天数卡死每天能发多少封**，避免新号一天打出去被 Gmail 封 SMTP。

真正把号养热，要靠你每天用这些额度发**正常、不像群发**的信，并尽量有人回复。

### 1. 每日额度（系统强制）

按接入后天数计算，单邮箱上限 40，再高也不会超过 50：

| 天数 | 每天最多 |
| --- | --- |
| 第 1–3 天 | 5 封 |
| 第 4–7 天 | 10 封 |
| 第 8–14 天 | 20 封 |
| 第 15–21 天 | 30 封 |
| 第 22 天起 | 40 封 |

额度在 **Gmail** 页和 **写信** 页都会显示，例如 `今日 2/5`。用完当天不能再发，第二天自动重置。

Gmail 页上的 **养号 D7** 表示现在是第 7 天；变成 **就绪** 表示已过 21 天爬坡。

### 2. 建议怎么养（你来发，系统来限）

前 3 天（每天 ≤ 5 封）：

- 发给会回你的人：自己的另一个邮箱、同事、熟人
- 标题、正文每封都不一样，写成对话，不要同一模板连发
- 让对方回一封，你再回，像正常通信
- 不要同一封「MailPost test」复制给很多人

第 4–14 天：

- 可以慢慢加真实联系人，仍保持个性化
- 每天尽量在额度内发完，但不要为了发满而群发套话
- 看 **已发送**，有退信就停，先查地址

第 15 天以后：

- 额度放开，仍避免短时间对很多 Gmail 发同一套话
- 进 Promotions 不等于没送到；要进 Primary，内容得像私人信

### 3. 养号期间不要做的事

- 一天用多台工具、多个 IP 狂发
- 买名单群发
- 带促销链接、图片、附件、「限时免费」
- 忽略退信和「垃圾邮件」投诉

Gmail 个人账号整体发送量本来就低，适合测试和小规模触达，不适合一天几百封。

## 三、设置签名（建议接入后就填）

打开 **设置**：http://localhost:3000/compliance

- **显示名称**：出现在信末签名
- **地址**：可选，会附在信末
- **站点**：用来拼退订链接，默认 `http://localhost:3000`

每封信末尾会自动带签名和退订地址。这能满足合规，也可能让 Gmail 把信分到 **Promotions**。一对一私人沟通若总进促销栏，多半是同一模板连发，或带了退订头。

---

## 四、联系人

打开 **联系人**：http://localhost:3000/contacts

- 只能自己添加，没有系统预置名单
- 填邮箱、名、姓、公司，点 **添加**
- 可删除
- 写信页可以从下拉框选用，自动带出邮箱和称呼

添加后即可作为收件人。发信时如果地址不在名单里，系统会按你手填的地址发出，并记入联系人。

---

## 五、话术

打开 **话术**：http://localhost:3000/sequences

- **新建**：写名称、标题、正文，点 **保存**
- 改完再保存，就是更新
- 可加多封（第 2 封、第 3 封），也可删某一封或整条话术
- 变量（可选）：`{{firstName}}` `{{company}}` `{{title}}` `{{industry}}` `{{lastName}}`  
  发送时按当前收件人替换

写信页也可以：

1. 「套用话术」选一条，标题正文被填上
2. 改完填「话术名称」，点 **存为话术** 或 **更新话术**

---

## 六、群发（按日限额排队）

打开 **群发**：http://localhost:3000/blast

这不是买名单狂轰。流程：

1. 先在 **联系人** 里自己加人  
2. 选发件 Gmail  
3. 可套用话术，或自己写标题正文（可用 `{{firstName}}`）  
4. 勾选收件人（全选 / 清空）  
5. 点 **开始群发**

系统会：

- 立刻把这些人排进队列  
- 当天只发「今日剩余额度」那么多封（养号第 1–3 天最多 5 封）  
- 大约每 25 秒发一封  
- 额度用完就停，第二天自动继续  
- 已退订、抑制名单、购买来源的地址会被跳过  
- 一次最多 200 人

任务卡片可以 **暂停**、**继续**、**取消剩余**、**立刻发下一封**。进程要用 `npm run start:prod` 或 systemd 挂着，关掉 Node 队列就不会往下发。

同一模板连发给很多 Gmail，容易进 Promotions。能个性化就写 `{{firstName}}`，前几天仍建议用写信一封一封养号。

---

## 七、写信发出

打开 **写信**：http://localhost:3000

1. 发件 Gmail（已接入的号）
2. 选用联系人，或手填「发给谁」
3. 称呼（会替换话术里的 `{{firstName}}`）
4. 可选：套用话术
5. 确认标题、正文
6. 点 **发送**

当天额度用完按钮会不可点。结果看页面提示，或到 **已发送**。

对方没看到时：查垃圾箱和 Promotions。第一封常进 Primary，同一模板第二封常进 Promotions。

---

## 八、已发送

http://localhost:3000/activity

单封和群发都会出现。排队中的会陆续变成已发送。可把某封标成硬退或已回复，硬退会把该联系人抑制，避免再发。

---

## 九、推荐日常顺序

1. Google 开通两步验证 + 应用专用密码  
2. **Gmail** 页接入  
3. **设置** 里填显示名  
4. 前 3 天每天用写信功能发几封给会回信的人（不超过 5 封）  
5. **联系人** 里加真实收件人  
6. **话术** 里写自己的正文  
7. **写信** 一封一封养号；名单熟了再用 **群发**，仍受日限额约束  

---

## 十、和 Gmail 页签的关系

- **Primary**：Gmail 认为是私人来信  
- **Promotions**：Gmail 认为是批量 / 营销  

系统无法指定进哪个页签。减少进促销栏的做法：每封都不一样、像对话、慢慢发、让对方把你加到通讯录或点「不是促销」。
